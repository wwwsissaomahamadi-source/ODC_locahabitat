Projet réaliser lors d'une formation full stack à Orange Digital Center Burkina. Cette partie concerne uniquement le frontend. Ce projet a pour but de faciliter l'accès à des locations d'habitation sur une plateforme numérique.

## Présentation et contexte

LocaHabitat est un projet de plateforme destiné à faciliter la recherche d’un logement à louer. Son objectif est de rendre la recherche plus simple en permettant aux futurs locataires de consulter des offres de location au même endroit.

Le projet est actuellement en développement. L’application Angular est initialisée, mais les écrans et fonctionnalités de recherche de logements restent à construire.

## Prérequis et Installation

Versions utilisées pour le développement :

- [Angular CLI](https://angular.dev/tools/cli) 22.3.0
- [Node.js](https://nodejs.org/) 26.13.1
- npm 11.20.0
- Windows x64
- Git pour récupérer et contribuer au dépôt.

Depuis un terminal, placez-vous à la racine du projet, puis installez les dépendances :

```bash
npm ci
```

## Utilisation et exemples

Démarrez le serveur de développement avec la commande Angular CLI :

```bash
ng serve
```

Ouvrez ensuite [http://localhost:4200] dans votre navigateur. L’application se recharge automatiquement lorsque les fichiers source sont modifiés.

## Guide de contribution

Les contributions sont les bienvenues. Pour proposer une modification :

1. Créez une branche dédiée à votre changement.
2. Effectuez vos modifications en suivant les conventions Angular et TypeScript déjà utilisées dans le projet.
3. Ouvrez une pull request en décrivant le changement et les vérifications effectuées.
